# 无限画布一期产品规格

- 状态：已确认
- 版本：v1.0
- 关联评审：[无限画布一期需求评审稿](../requirements/infinite-canvas-review.md)
- 关联架构：后续补充 ADR

## 1. 产品目标

让用户在一个可保存的无限画布中组织文本节点，并通过 Agent 生成、修改和连接节点。Agent 的所有画布写入都必须先以结构化变更展示给用户，用户确认后才提交。

## 2. 一期范围

### 包含

- 单用户私有项目。
- 项目创建、列表、打开、重命名和删除。
- 无限画布平移、缩放、网格背景和视口恢复。
- 文本节点创建、编辑、移动、选中、框选、删除。
- 有向连接创建和删除。
- 撤销和重做当前会话中的画布操作。
- Agent 会话、流式消息、运行状态、取消、失败和重试。
- Agent Operation 预览、确认提交和 revision 冲突提示。
- 服务端项目持久化；浏览器只保留临时草稿。

### 不包含

- 多人协作、分享、权限和在线状态。
- 视频、音频和图片生成供应商。
- 工作流节点、端口类型和执行顺序。
- Python 运行时、任意代码执行和浏览器自动化。

## 3. 核心用户流程

### 3.1 创建和编辑项目

1. 用户进入项目列表，创建项目并填写标题。
2. 系统打开项目详情，显示空画布和默认视口。
3. 用户通过工具栏或快捷键创建文本节点。
4. 用户编辑节点内容、拖动位置或建立连接。
5. 前端将用户意图转换为 Operation，提交成功后更新本地快照和 revision。
6. 页面刷新后，系统从服务端恢复节点、连接、视口和标题。

### 3.2 Agent 生成变更

1. 用户在 Agent 面板输入目标，例如“为发布计划创建三个步骤节点并连接起来”。
2. 系统创建 Agent Run，SSE 推送运行状态和文本增量。
3. Agent 返回说明和结构化 Operation 批次。
4. 服务端校验 Operation，但不改变项目。
5. 前端在画布中预览新增、修改、移动、删除和连接。
6. 用户确认后，客户端提交 `expectedRevision` 和 Operation 批次。
7. 服务端在事务中再次校验并原子提交，返回新 revision。
8. revision 冲突时，用户可以刷新项目后重新生成或放弃本次变更。

## 4. 画布行为规格

### 4.1 坐标和视口

- 节点位置和尺寸使用世界坐标。
- 视口包含 `x`、`y` 和 `zoom`，范围由前端限制在 `0.1` 到 `4`。
- 缩放以指针所在位置为中心，不改变该位置对应的世界坐标。
- 视口保存属于项目体验状态，不增加 Agent 的语义 revision。

### 4.2 节点

- 节点必须有稳定 ID、标题、位置、尺寸和类型。
- 文本节点内容不能为空白；标题可由内容前缀生成，也可单独编辑。
- 移动操作使用最终位置提交，不为拖动过程中的每个像素创建服务端 revision。
- 删除节点会级联删除关联连接。
- 单次 Operation 批次最多创建或修改 100 个节点，超出时拒绝。

### 4.3 连接

- 连接为有向边，源节点和目标节点必须存在。
- 不允许自连接和重复连接。
- 一期连接只表示上下文/引用关系，不代表可执行流程。
- 删除任一端节点时，关联连接必须一并删除。

### 4.4 撤销和重做

- 前端维护当前页面会话的操作历史。
- 撤销和重做以 Operation 批次为单位。
- 刷新页面后不要求恢复历史栈。
- Agent 确认提交视为一个历史批次，不能拆成多个用户可见步骤。

## 5. Agent 行为规格

- Agent Run 状态：`queued`、`running`、`succeeded`、`failed`、`cancelled`。
- Agent 可以读取当前项目快照和选中节点，但不能直接写数据库。
- Agent 输出必须包含自然语言说明和可选 Operation 批次。
- Operation 必须通过 JSON Schema、权限规则和 Canvas domain validator。
- 非法输出只能形成失败 Run，不得修改项目 revision。
- 用户取消后，Run 不得提交 Operation；已经提交的事务不回滚到取消之前。
- SSE 断开后，客户端通过 Run 查询接口恢复最终状态。

## 6. 数据保存规格

- 项目快照、节点、连接和 Agent 会话保存于服务端。
- 画布 JSON 不内嵌大文件；图片仅保存未来可用的 `assetId`。
- 项目写入使用 `expectedRevision` 乐观并发校验。
- 重复请求使用客户端请求 ID 或幂等键去重。
- revision 冲突返回 HTTP 409，并包含服务端当前 revision。

## 7. 接口验收清单

- `GET/POST /projects`
- `GET/PATCH/DELETE /projects/{projectId}`
- `POST /projects/{projectId}/operations`
- `GET /projects/{projectId}/agent/sessions`
- `POST /projects/{projectId}/agent/runs`
- `GET /agent/runs/{runId}/events`
- `POST /agent/runs/{runId}/cancel`

OpenAPI 必须描述请求、响应、错误码、Operation 类型、Run 状态和 SSE 事件载荷；前后端不得维护第二份互相矛盾的契约。

## 8. 验收标准

- 能完成“创建项目—创建文本节点—连接节点—刷新恢复”的闭环。
- 能完成“输入 Agent 目标—流式返回—预览 Operation—确认提交—刷新恢复”的闭环。
- 非法节点、边、Operation 和 revision 都有稳定错误响应。
- Agent 失败、取消、SSE 断线和重复提交不会产生脏数据。
- 1,000 个文本节点的打开、平移和缩放仍可交互；具体性能阈值在实现阶段补充基准测试。
- 前端测试覆盖画布 reducer、Operation 预览和 SSE 状态转换；后端测试覆盖领域校验、事务提交和 revision 冲突。
